# triumph-digital: сайт digital-сервиса

Продакшен сайта [triumph-digital.ru](https://triumph-digital.ru): статика плюс серверная функция приёма заявок. Живёт на Vercel, домен подключён, форма работает.

Сделан намеренно без фреймворка. Для сайта из пяти страниц с одной формой Next.js это лишний вес: холодный старт, сборка, зависимости, которые надо обновлять. Здесь честная статика, которая грузится мгновенно с телефона, и одна функция на бэкенде.

## Что внутри

- Пять страниц: главная, услуги, портфолио, о сервисе, контакты
- `api/send.js`: приём заявки с формы и отправка в Telegram. Токен и адрес чата берутся из переменных окружения, в коде их нет
- Тёмная тема с золотым акцентом, типографика на Unbounded и Golos Text
- `robots.txt`, Open Graph картинка, фавикон

## Как устроена форма

Заявка уходит POST-запросом в серверную функцию, та валидирует поля и шлёт сообщение в Telegram-бот. Уведомление приходит владельцу за секунды, без почты и без сторонних сервисов вроде Formspree, которые за это берут деньги и держат данные у себя.

## Запуск локально

```bash
npx serve .           # статика
vercel dev            # со серверной функцией
```

Для работы формы нужны переменные `BOT_TOKEN` и `CHAT_ID`.
